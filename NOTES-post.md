**Post produzione / Post-production course**

**macOS** (Terminal, REAPER closed):

```
curl -fsSL https://github.com/animALavoro/Objet/releases/download/post/install-mac.sh | bash
```

**Windows** (PowerShell, REAPER closed):

```
irm https://github.com/animALavoro/Objet/releases/download/post/install-windows.ps1 | iex
```

Then import *Post_Produzione.ReaperConfigZip* in REAPER (*Preferences > General > Import configuration…*). Guide: [Italiano](https://github.com/animALavoro/Objet/blob/main/docs/post/guida.md) · [English](https://github.com/animALavoro/Objet/blob/main/docs/post/guide.md).
