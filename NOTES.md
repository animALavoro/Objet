**macOS** (Terminal, REAPER closed):

```
curl -fsSL https://github.com/animALavoro/Objet/releases/latest/download/install-mac.sh | bash
```

**Windows**: unzip each `*-Windows.zip` and copy the `.vst3` to `C:\Program Files\Common Files\VST3\`.

Then in REAPER: *Preferences > Plug-ins > VST > Clear cache/re-scan*. Details: README of this repository (English and Italian).
